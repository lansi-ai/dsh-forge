# DSH Forge v0.1.1-rc.2

> 预发布版（Pre-release）。`0.1.1` 线第二个 `rc` 候选，继续稳定化验证。
> 上游基线：`@deepseek-ai/dsh` `0.1.5-rc.2`（由 `0.1.5-alpha.2` 升级）
> 完整变更：https://github.com/lansi-ai/dsh-forge/compare/v0.1.1-rc.1...v0.1.1-rc.2

## ✨ 本版亮点

- **插件列表全自研** —— 「设置 → 插件 → 插件列表」改为桌面定制口径：全局插件 / 预设组成两级分组 + 预设切换器 + 承载面筛选；并修掉「宿主侧插件搜不到」的根因。
- **上游基线升级至 `0.1.5-rc.2`** —— 一次纳入上游 `rc.1` / `rc.2` 两个版本：默认模型更新、右侧栏预览与统计打磨、反馈与交付文件优化；本项目**零代码适配**。

## 🧩 插件列表（全自研）

**界面**（自研件接管 `settings.plugins.tab`，官方同名 Tab 已互斥排除）

- 两级分组：「全局插件」与「预设组成」。
- 「预设组成」组带**预设切换器**：可直接对比不同预设下模型实际可见的插件，条目数与官方「会话插件 · N 个」一致（极简模式 = 6 行）。
- 承载面筛选 chips + 精简两行摘要，点击行展开详情。
- 已停用 / 条件装配的行如实列出，不再隐去。

**数据**（根因修复）

- 插件清单由「仅客户端资源图谱」升级为**三源合并**：Cordis 真实 Loader 条目 ∪ 客户端资源图谱 ∪ 预设组成。
- 此前仅读客户端图谱，导致**宿主侧插件（如 `tool-pwsh`）在列表中完全缺失**；现在与官方口径一致，读真实插件树。

## ⚠️ 升级须知

1. **本版为预发布（Pre-release）**：不会进入 GitHub "Latest release"，`stable` 渠道不会收到本版推送。
2. **应用内「rc」渠道本版仍不会自动发现更新**：更新描述符 `latest-rc.yml` 未产出（实测 404），请从本页 **Assets 手动下载**安装。已知问题，修复方案已列入计划。
3. **若下载失败**：国内直连 `github.com` 可能被重置。可在 通用设置 → 网络设置 选择「手动设置」填入本地代理（如 `127.0.0.1:7890`）后重试；本版资产已实测经代理可匿名正常下载。
4. **品牌图标**：桌面快捷方式与安装包图标随本版安装包更新；你自行上传的自定义图标不会被覆盖。
5. **动态插件安全提示**：创造模式下的动态插件等同 bash 级访问权限，`vm` 不是安全边界 —— 请只运行你信任的代码。
